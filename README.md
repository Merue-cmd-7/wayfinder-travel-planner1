# Wayfinder Travel Planner

Client-side web development mini-project built with HTML5, CSS3, JavaScript, jQuery, and the Open-Meteo public weather API.
Repository: https://github.com/Merue-cmd-7/wayfinder-travel-planner1

## Pages
- `index.html`: Home page with destination overview, travel style cards, and live city temperature lookup via Open-Meteo.
- `planner.html`: Trip entry form validated with jQuery Validate, trip list rendered from an array of objects, search filter, and delete buttons.
- `tips.html`: Interactive packing checklist (add, toggle packed status, remove) and travel planning tips.

## How to Run Locally
1. Download or clone the repository.
2. Open `index.html` in a web browser (an active internet connection is needed for jQuery/jQuery Validate CDNs and live Open-Meteo weather requests).
